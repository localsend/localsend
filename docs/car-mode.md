# Автомобильный режим (Qiyuan A06)

Документ описывает доработку под широкий экран автомобиля: 15,6 дюйма, 2560 × 1440.

## 1. Как включается режим

Режим включает три условия:

1. Ширина окна не меньше 1200 логических точек.
2. Ширина больше высоты.
3. Платформа — Android.

Пользователь может переопределить выбор. Переключатель «Автомобильный режим» находится в настройках, раздел «Общие».
Значение хранится в ключе `ls_car_mode`. Пустое значение означает автоопределение.
Если пользователь ставит переключатель в то же значение, что даёт автоопределение, запись стирается.

Код: `app/lib/widget/car_mode_scope.dart`, `app/lib/provider/car_mode_provider.dart`.

## 2. Что меняется на широком экране

| Элемент | Телефон | Автомобиль |
|---|---|---|
| Главный экран | Одна страница | Две панели рядом: приём и отправка |
| Активная панель | — | Шире второй, в отношении 3 к 2 |
| Настройки | Одна колонка | На всю ширину |
| Колонка контента | 600 dp | 1400 dp |
| Кнопки выбора файлов | 90 × 65 dp | 180 × 120 dp |
| Плитка устройства | отступ 15 dp, иконка 46 dp | отступ 24 dp, иконка 64 dp |
| Боковая панель | С подписями | Компактная |
| Тема | По настройке | Тёмная, если не выбрана светлая |

Файлы:

- `app/lib/widget/responsive_builder.dart` — профили и ширина колонки.
- `app/lib/widget/responsive_list_view.dart` — ширина колонки по профилю.
- `app/lib/pages/home_page.dart` — две панели.
- `app/lib/widget/big_button.dart`, `app/lib/widget/list_tile/*` — размеры.

## 3. Системная интеграция

- Ориентация фиксируется в альбомной, пока режим включён.
- Системные панели скрываются: `SystemUiMode.immersiveSticky`.
- Системный масштаб шрифта ограничен сверху значением 1.3.
- Активность помечена как `resizeableActivity`, поэтому головное устройство может показывать её в своём окне.

Файлы: `app/lib/config/theme.dart`, `app/lib/config/init.dart`, `app/android/app/src/main/AndroidManifest.xml`.

## 4. Сборка

Требуется Flutter из `.fvmrc` (3.41.9) и Rust toolchain.

```bash
cd app
fvm flutter pub get
fvm dart run build_runner build
fvm dart run slang
fvm flutter build apk --release --target-platform android-arm64
```

Для головного устройства без Google Play Services используйте FOSS-сборку:

```bash
bash support/scripts/remove_proprietary_dependencies.sh
```

Подпись задаётся в `app/android/key.properties`.

### Сборка, которая ставится рядом с обычным LocalSend

Флаг `carBuild` меняет идентификатор пакета и имя приложения:

```bash
cd app
fvm flutter build apk --release --android-project-arg=carBuild=true
```

Результат:

| Свойство | Обычная сборка | Сборка для автомобиля |
|---|---|---|
| Идентификатор | `org.localsend.localsend_app` | `org.localsend.localsend_app.a06` |
| Имя | LocalSend | LocalSend A06 |
| Версия | `1.18.2` | `1.18.2-a06` |

Разные идентификаторы дают два следствия:

1. Android ставит обе версии и не удаляет одну ради другой.
2. Настройки и история передач у версий раздельные.

Ключ подписи лежит в `app/android/app/a06-release.jks`. Пароль записан в `app/android/key.properties`.
Оба файла в `.gitignore`. Храните их: без ключа обновления не установятся поверх.

## 5. Установка

```bash
adb install -r app/build/app/outputs/flutter-apk/app-release.apk
```

## 6. Проверка

1. Запустить приложение на экране 2560 × 1440.
2. Убедиться, что видны две панели.
3. Проверить приём файла с телефона.
4. Проверить отправку файла на телефон.
5. Проверить переключатель режима в настройках.
6. Перезапустить приложение и убедиться, что выбор сохранился.

## 7. Ограничения

- Строки нового переключателя лежат в `settings_tab.dart`, а не в файлах перевода. Причина: файлы `app/lib/gen/` генерируются через slang, а генератор в этой ветке не запускался.
- Автоопределение работает только на Android. На Windows и Linux режим включается только вручную.
- Если головное устройство блокирует multicast, используйте кнопку ручного ввода адреса на панели отправки.
